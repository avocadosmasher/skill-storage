## 무엇을 하나

`find-skills`는 사용자가 원하는 기능을 이미 설치할 수 있는 스킬이 있는지 찾아 주는 스킬입니다. `npx skills` CLI(스킬 생태계의 패키지 매니저)로 [skills.sh](https://skills.sh/) 리더보드를 먼저 확인하고, 필요하면 `npx skills find`로 키워드 검색을 돌려 설치 수와 출처(공식 조직인지, GitHub 스타 수가 얼마인지)를 확인한 뒤 설치 명령과 함께 추천합니다. 적당한 스킬이 없으면 직접 도와주거나 `npx skills init`으로 사용자가 새 스킬을 만들도록 안내합니다.

결과물: 추천 스킬 이름·설명·설치 수·출처와 설치 명령(`npx skills add <owner/repo@skill> -g -y`), 또는 적합한 스킬이 없다는 안내.

## 언제 쓰나

"이런 거 하는 스킬 있어?", "X 하는 법 알아?", "에이전트 기능을 확장하고 싶다" 같은 요청에 model-invoked로 에이전트가 알아서 꺼내 씁니다. React/테스트/배포/문서화처럼 흔한 작업 도메인을 물을 때 특히 유용합니다. 이미 이 저장소에 있는 스킬로 할 수 있는 일이면([SCOPE.md](../../SCOPE.md) 기준) 새로 찾지 않고 그 스킬을 바로 씁니다.

## 자주 묻는 질문

**검색 결과를 그대로 추천해도 되나요?**
아닙니다. 설치 수(1천 건 이상 선호, 100건 미만은 주의), 출처(공식 조직인지), GitHub 스타 수를 확인한 뒤에 추천합니다.

**스킬을 찾았으면 바로 설치하나요?**
사용자가 원할 때만 설치합니다. 설치는 `npx skills add <owner/repo@skill> -g -y`로, `-g`는 사용자 전역 설치, `-y`는 확인 생략입니다.

## 잘 되고 있다는 신호

- 추천마다 설치 수와 출처가 함께 제시됩니다.
- 검색 결과가 없으면 추천을 지어내지 않고, 직접 도와주거나 `npx skills init`을 안내합니다.
