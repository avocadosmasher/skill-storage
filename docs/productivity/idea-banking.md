## 무엇을 하나

`idea-banking`은 떠오른 아이디어(만들고 싶은 도구, AI 스킬, Agent, 자동화, 공부할 주제 등)를 **적은 마찰로 바로 기록**하고, 시간이 생겼을 때 다시 꺼내 발전시키게 돕습니다.

- 기록할 때는 말한 내용을 **원문 그대로** 남기고, 짧은 제목과 한 줄 요약만 붙여 바로 저장합니다. 질문을 이어 가며 저장을 미루지 않습니다.
- 에이전트가 덧붙이는 생각은 `AI 첨언`으로 원문과 따로 저장해, 내가 한 말과 AI의 제안이 섞이지 않게 합니다.
- 나중에 "전에 적은 회의 관련 아이디어 찾아줘", "이거랑 비슷한 거 있었나?", "이 아이디어 구체화해 줘"처럼 요청하면 저장된 기록을 검색·비교하고, 구체화한 내용은 날짜를 붙인 메모로 이어 붙입니다.

기록은 아이디어 하나당 Markdown 파일 하나(`ideas/IB-날짜-시간-ID.md`)로 남습니다. 별도 DB가 없어 Obsidian 같은 편집기로 직접 열어 볼 수 있습니다. 실행에는 Python 3.10 이상이 필요합니다(외부 라이브러리 없음).

## 언제 쓰나

model-invoked 스킬입니다. "이 아이디어 저장해 둬", "아이디어 뱅크에서 찾아줘", "예전에 적은 것과 비교해 줘"처럼 말하면 에이전트가 이 스킬을 씁니다.

작업 중에 떠오른 생각을 흐름을 끊지 않고 남겨 두고 싶을 때 쓰세요. 일반 업무 메모나 할 일 목록, 지금 바로 구현해 달라는 요청에는 쓰지 않습니다. 계획을 깊이 따져 결정까지 내리고 싶다면 `grill-me-plus`가 맞습니다.

### 저장 위치

기본은 홈 폴더의 `idea-bank/`입니다. 다른 곳에 두려면 환경 변수 `IDEA_BANK_PATH`에 절대 경로를 넣습니다. Claude Code에서는 `~/.claude/settings.json`에 이렇게 적으면 됩니다.

```json
{
  "env": {
    "IDEA_BANK_PATH": "C:/Users/me/notes/idea-bank"
  }
}
```

### `/ideas` 패널 (선택 설치)

Claude Code에서는 저장한 아이디어를 옆 패널에서 훑어보는 mod `idea-bank-viewer`를 따로 설치할 수 있습니다. 요약 목록, 검색, 페이지 넘기기, 보관 기록 보기와 함께 원문·AI 첨언·추가 기록을 나눠 보여 줍니다. 읽기만 하고 기록을 고치지는 않습니다.

```bash
claude plugin install idea-bank-viewer@avocadosmasher
```

설치한 뒤 `/ideas`를 입력하면 패널이 열립니다. 패널은 스킬과 같은 규칙으로 저장 위치를 찾습니다(`IDEA_BANK_PATH`, 없으면 홈 폴더의 `idea-bank/`). `/config`의 `bankPath`로 패널만 다른 폴더를 보게 할 수도 있습니다. mod는 스킬보다 넓은 권한으로 동작하므로 [코드](../../mods/idea-bank-viewer/)를 확인하고 설치하세요.

## 자주 묻는 질문

**저장하자마자 왜 이것저것 묻지 않나요?**
떠오른 순간에 질문이 이어지면 기록 자체를 미루게 됩니다. 그래서 일단 원문을 저장하고, 구체화는 나중에 따로 요청할 때 합니다.

**비슷한 아이디어를 자동으로 합쳐 주나요?**
합치지 않습니다. 해결할 문제, 대상, 기대 결과를 비교해 "같은 목표의 변형인지, 연관된 별개 아이디어인지"를 근거와 함께 알려 주고, 관련 ID를 연결하거나 비교 메모를 남깁니다. 원문은 지우지 않습니다.

**검색에서 안 나오면 중복이 없다는 뜻인가요?**
아닙니다. 검색은 단어 일치 방식이라 표현이 다르면 놓칠 수 있습니다. 에이전트는 동의어로 넓혀 찾되, 실제 파일을 읽지 않은 비교는 추정이라고 밝힙니다.

**오래된 아이디어는 정리되나요?**
시간이 지났다고 삭제하거나 보관하지 않습니다. 상태(`inbox`, `exploring`, `ready`, `active`, `done`, `archived`)는 사용자가 요청하거나 결정했을 때만 바뀝니다. 자동 알림도 없습니다.

## 잘 되고 있다는 신호

- 아이디어를 말하면 한두 줄의 "저장했어요" 확인과 파일 링크만 돌아옵니다.
- 기록 파일을 열면 내가 한 말과 AI 첨언이 다른 섹션에 있습니다.
- 몇 주 뒤 다른 표현으로 물어도 예전 기록을 찾아 옵니다.
- 구체화한 내용이 원문 아래에 날짜별로 쌓여 있습니다.
