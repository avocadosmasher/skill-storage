# 007. Claude Code 예산 어댑터는 커밋 직전에 파일을 쓰는 mod로 만든다

- 날짜: 2026-10-14
- 상태: 채택
- 반영: gated-tdd-budget 0.1.0

## 배경

[006](./006-budget-signal-harness-neutral.md)에서 예산 신호의 전달(git `post-commit` 훅)과 수치 공급(도구별 어댑터)을 나눴다. 어댑터가 없으면 이번 세션에서 끝낸 단위 수만 보는데, 단위 크기가 제각각이라 실제 컨텍스트 소모와 어긋날 수 있다. Claude Code는 mod에서 `$.session.usage()`로 컨텍스트 사용률과 사용 한도를 바로 읽을 수 있으므로 첫 어댑터로 만든다.

남은 문제는 mod가 읽은 수치를 커밋 직후 실행되는 `budget.mjs`에 어떻게 넘기느냐였다.

## 선택지

1. **`session.measure` 이벤트마다 파일을 쓴다.**
   - 단점: 이 이벤트는 메인 턴이 끝날 때 온다. 자리를 비운 사이 길게 이어지는 자동 진행은 턴 하나 안에서 일어나므로, 커밋 시점에는 파일이 낡아 있다.
2. **`git commit` 명령 앞에 환경 변수를 붙이도록 명령을 고친다** (`export GATED_TDD_BUDGET=...; git commit ...`).
   - 장점: 파일이 필요 없고, `cd`로 다른 저장소에 커밋해도 전달된다.
   - 단점: 바뀐 명령으로 권한 검사가 다시 이뤄진다. 사용자가 `Bash(git commit:*)` 같은 허용 규칙을 써 왔다면 갑자기 승인 요청이 뜬다. 에이전트가 실행한 명령과 실제 실행된 명령이 달라진다.
3. **`git commit`을 실행하는 Bash 호출 직전에 `.git/gated-tdd-budget.json`을 쓴다.** (채택)
   - 장점: 명령을 바꾸지 않는다. 커밋 직전 수치라 낡지 않는다. 006의 파일 계약을 그대로 쓴다.
   - 단점: 작업 폴더에서 위로 찾은 저장소에만 쓴다. `cd 다른-저장소 && git commit`이면 그 커밋은 단위 수 기준으로 돌아간다.
4. **`$.process`로 `git rev-parse --git-path`를 실행해 정확한 위치를 얻는다.**
   - 단점: 프로세스 실행 권한이 필요해 mod의 권한이 넓어진다. 워크트리는 `.git` 파일을 읽어 따라가면 같은 결과를 얻는다.

## 결정

3을 택했다.

- `tool.call` 훅(Bash)에서 명령이 `git commit`이면, 작업 폴더에서 위로 `.git`을 찾는다. 워크트리처럼 `.git`이 파일이면 `gitdir:`을 따라간다.
- `$.session.usage()`를 읽어 006의 계약대로 쓴다. 압축 직후처럼 사용률이 비어 있으면 `context`를 빼서 `budget.mjs`가 단위 수로 판단하게 한다.
- 무엇이 실패해도 커밋은 그대로 실행한다. 이 mod는 커밋을 막는 장치가 아니다.
- 권한은 세션 사용량 읽기, `.git` 찾기용 파일 읽기, 파일 하나 쓰기뿐이다. ADR 0002대로 별도 플러그인으로 두고 사용자가 골라 설치한다.

## 버린 것과 미룬 것

- 상태줄에 예산 수치를 늘 보여 주는 기능은 넣지 않았다. 사용자의 기존 상태줄과 부딪힐 수 있고, 이 mod의 목적(에이전트의 판단 재료)과 다르다.
- Codex 어댑터는 훅 입력에 사용량이 없어 만들지 않았다. Codex가 사용량을 노출하면 같은 파일 계약으로 만든다.

## 다시 볼 신호

- 다른 저장소에 `cd`해서 커밋하는 흐름이 자주 쓰여 수치가 빠진다.
- Claude Code가 mod API의 `session.usage`나 `tool.call` 형태를 바꾼다. 형식이 초기 공개(EARLY ACCESS) 단계라고 명시되어 있다.
