# 005. 확인 안 된 확인 지점은 넘어가지 않고, 다음 세션도 확인부터 시작한다

- 날짜: 2026-10-14
- 상태: 채택
- 반영: skill-storage 1.5.0

## 배경

확인 지점에 도달했는데 사용자가 자리에 없으면 어떻게 할지 정해야 했다. 제안한 선택지는 "확인 안 된 가시적 변경이 세션을 넘기지 않게 하는 상한을 둘지"였다.

## 선택지

1. **확인을 기다리는 동안 다음 묶음을 계속 진행한다.**
   - 장점: 멈추는 시간이 없다.
   - 단점: 확인 안 된 것 위에 계속 쌓인다. [004](./004-checkpoints-at-feature-bundles.md)의 경계가 의미를 잃는다.
2. **확인 지점에서 멈추고, 확인 전에는 다음 묶음으로 넘어가지 않는다.** (채택)
   - 사용자의 말: 시각적인 것이 바뀌는 부분은 그게 맞다. 이전에 확인하지 않고 껐다면 다음 세션은 확인부터 시켜 주는 게 맞다.

## 결정

- 확인 지점에 도달하면 확인 보고를 하고 멈춘다. 확인 전에는 다음 묶음을 시작하지 않는다.
- 확인 지점은 정의상 "직접 해볼 것이 있는 곳"이므로, 시각 변경뿐 아니라 모든 확인 지점에 같은 규칙을 적용한다.
- STATUS.md의 "확인 대기"에 남긴다. 다음 세션은 0절에 따라 확인 대기부터 처리한다. 실제 확인 기록이 있으면 다시 묻지 않는다(1.4.0의 "판정 대기" 대조 규칙과 같음).

## 버린 것과 미룬 것

- 확인을 기다리는 동안 그 묶음에 의존하지 않는 자동 단위를 진행하는 안은 규칙을 복잡하게 만들어 미뤘다.

## 다시 볼 신호

- 사용자가 자리를 비운 장시간 작업에서 확인 대기로 멈춰 있는 시간이 아깝다는 피드백이 나온다.
