# 006. 예산 신호는 커밋 직후 git 훅이 임계치를 넘을 때만 알린다

- 날짜: 2026-10-14
- 상태: 채택
- 반영: skill-storage 1.5.0 (Claude Code 어댑터는 [007](./007-claude-code-budget-adapter.md))

## 배경

승인 없이 진행하는 구간이 길어지면, 남은 컨텍스트와 사용 한도를 보고 작업을 끊을지 스스로 판단해야 한다. 사용자는 Claude Code뿐 아니라 Codex 같은 다른 에이전트도 쓰므로 특정 도구에 묶이면 안 된다.

확인한 사실 (2026-10-14):

- Claude API 문서상 남은 컨텍스트를 모델에 자동으로 알려 주는 기능은 Sonnet 4.5·4.6·5와 Haiku 4.5에만 있다. Opus 4.7 이후, Sonnet 5.5, Haiku 5.5에는 없다. "남은 컨텍스트를 보고 판단하라"고만 쓰면 모델은 추측한다.
- Claude Code의 셸 명령 훅 입력에는 사용량 필드가 없다. 상태줄 스크립트 입력에는 컨텍스트 사용률과 구독의 5시간·7일 한도가 있다.
- Claude Code mod(빌드 2.1.299)는 `$.session.usage()`로 컨텍스트와 사용 한도를 바로 읽고, `tool.call` 훅으로 도구 결과 뒤에 모델만 읽는 문맥을 붙일 수 있다.
- Codex CLI 훅(v0.133 기준)의 입력에도 사용량 필드는 없다. `transcript_path`는 있지만 형식이 불안정하다고 문서화되어 있다.
- 자동 압축이 일어나면 호출했던 스킬 본문은 스킬당 5,000토큰까지만 다시 들어간다.

## 선택지

1. **매 도구 호출마다 훅으로 수치를 넣는다.**
   - 단점: 컨텍스트를 쓰고 소음이 된다. 끊는 판단은 단위 경계에서만 의미가 있다(단위 중간에 끊으면 반쪽 작업이 남음).
2. **Claude Code mod만 쓴다.**
   - 단점: 다른 에이전트에서는 동작하지 않는다.
3. **커밋 직후 git `post-commit` 훅이 알리고, 수치 공급은 도구별 어댑터로 분리한다.** (채택)
   - 장점: 단위마다 커밋하므로([003](./003-commit-before-approval.md)) 커밋이 곧 단위 경계다. 어떤 에이전트든 `git commit`을 셸로 실행하고 그 출력을 읽으므로 전달 경로가 도구와 무관하다.
   - 단점: 정확한 수치는 어댑터가 있어야 들어온다. 없으면 대리 지표만 쓴다.

## 결정

- `scripts/budget.mjs`
  - `start`: 세션 시작 시 기준 커밋과 시각을 `.git/gated-tdd-session.json`에 남긴다.
  - `check`: `post-commit` 훅이 호출한다. 임계치를 넘었을 때만 `[예산] ...` 한 줄을 출력하고, 넘지 않으면 아무것도 출력하지 않는다. 언제나 0으로 끝나 커밋을 막지 않는다.
- 수치 공급원
  - 어댑터 파일 `.git/gated-tdd-budget.json`이 있고 최신이면 그 값(컨텍스트 %, 사용 한도 %)을 쓴다. 어댑터는 도구별로 따로 만든다(Claude Code는 mod로 커밋 직전에 쓰는 방식이 유력).
  - 없으면 대리 지표: 이번 세션에서 끝낸 단위 수(세션 시작 이후 커밋 수).
- 판단 규칙 (시작값, `.gated-tdd.json`에서 조정)
  - 컨텍스트 60% 이상 또는 단위 6개 이상: 작은 단위만.
  - 컨텍스트 75% 이상, 사용 한도 85% 이상, 또는 단위 10개 이상: STATUS.md 인계를 갱신하고 정지, 새 세션 권장.
  - 끊는 것도 묻지 않고 알리는 대상이다.
- 압축보다 새 세션을 권한다. STATUS.md 하나로 이어 가는 구조가 이미 있고, 압축 뒤 스킬 본문이 잘릴 수 있다. 같은 이유로 SKILL.md는 핵심만 남기고 상세는 `references/`로 뺐다.

## 버린 것과 미룬 것

- Claude Code 어댑터(mod)와 Codex 어댑터는 이번 변경에 넣지 않았다. 파일 계약만 정해 두고 후속으로 만든다.
- 상태줄 스크립트가 파일을 쓰는 어댑터는 사용자의 기존 상태줄과 부딪힐 수 있어 우선순위를 낮췄다.

## 다시 볼 신호

- 대리 지표(단위 수) 임계치가 실제 컨텍스트 소모와 크게 어긋난다. (단위 크기 편차가 큼)
- 압축 뒤 규칙을 놓치는 일이 관찰된다. (SKILL.md를 더 줄이거나 임계치를 낮춤)
