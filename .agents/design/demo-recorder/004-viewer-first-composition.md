# 004. 보는 사람이 따라오는 영상 구성

- 날짜: 2026-11-24
- 상태: 채택
- 반영: 첫 추가 (`references/demo-guidelines.md`, `references/structures/usecase-flow.md`)

## 배경
첫 데모 영상을 네 번 고치며 사용자가 짚은 것: 자막이 너무 빨리 지나감(0.1초 깜빡임 포함), 장면이 갑자기 바뀜, 100% 배율에서 번호가 버튼·글자를 가림, 장면 사이 흐름 띠의 강조가 뒤죽박죽 움직임, 걸린 시간을 숫자로 보여 주면 좋겠음, 영상 하나로(이어 붙인 판이 아니라), 5분 안.

## 선택지 (장면 순서)
- 담당자가 화면을 여는 순서(노트 → 상세 → 콘솔): 다시 녹화가 필요 없지만 흐름 띠의 불이 끝 → 가운데 → 처음으로 움직임
- 처리 순서(입력 → 받기 → 가리기 → 정리·검증 → 노트): 흐름 띠가 오른쪽으로만 나아감. 상세 화면을 링크 대신 API로 주소를 읽어 열어야 함
- 순서는 두고 흐름 띠를 화면 진행 막대로 바꾸기: 편집만으로 되지만 아키텍처와의 연결이 약해짐

## 결정
처리 순서(사용자 선택). 원칙은 `references/demo-guidelines.md`에, 이 구성은 사용자가 자주 쓸 기본 구조로 `references/structures/usecase-flow.md`와 뼈대 시나리오로 남긴다. 편집기는 자막 2초 미만·5분 초과를 경고하고, 번호는 페이지 배율에 맞춰 상자 바깥에 그리며, 카드는 이어지면 바로 바뀌고 끝은 다음 화면으로 녹아든다.

## 버린 것과 미룬 것
- 화면 오른쪽 위에 상시 진행 띠: 화면이 복잡해져 보류
- 모든 영상을 이 구조로: 기능 투어·튜토리얼은 다른 구조가 맞다. 새 구조는 `references/structures/`에 더한다

## 다시 볼 신호
- 다른 영상에서 같은 종류의 지적(속도, 가림, 순서)이 다시 나오면 원칙이 편집기 검사로 충분히 강제되지 않는다는 뜻이다
