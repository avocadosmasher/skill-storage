# 003. 화면 위 설명은 편집에서 그린다

- 날짜: 2026-11-24
- 상태: 채택
- 반영: 첫 추가

## 배경
되돌릴 수 없는 단계(실제 티켓 만들기)가 있는 녹화는 다시 찍을 때마다 데이터가 생긴다. 자막 문구 하나 고치려고 다시 찍으면 안 된다.

## 선택지
- 페이지에 상자·자막을 넣고 찍기: 고치려면 다시 녹화
- 녹화기가 단계마다 시각·상자 위치·커서·기다림 구간을 시간표로 남기고, 편집기가 그리기

## 결정
시나리오는 값만 담는 `.mjs`, 녹화기(Node, ego 안)가 기본값을 채운 시나리오를 `timeline.json`에 실어 편집기(Python)는 시간표만 읽는다. 상자는 화면이 멈춘 구간(hold)에서만 보이고 앞뒤 두 번 재서 움직이거나 가려지면 경고한다. 기다림의 자르기·배속, 장면 카드 끼우기, 로딩 중 멈춘 화면 줄이기는 원본 시각 ↔ 출력 시각 사상(`timemap.py`)으로 처리해, 녹화 뒤에도 `--wait-edit`처럼 바꿀 수 있다.

## 다시 볼 신호
- 상자 대상이 멈춘 동안에도 움직이는 화면(애니메이션, 실시간 목록)이 많으면 프레임마다 위치를 재는 방법이 필요하다
