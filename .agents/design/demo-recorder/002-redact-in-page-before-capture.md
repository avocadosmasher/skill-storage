# 002. 가리기는 페이지에서, 캡처 전에

- 날짜: 2026-11-24
- 상태: 채택
- 반영: 첫 추가 (Fable 5.2 검토 17건 반영)

## 배경
사내 화면에는 사용자 실명·아바타·이메일이 여러 곳(머리줄, 요청자 칸, 작성자, 페이지 소유자)에 보인다. 데모는 가상 데이터로 하지만 로그인한 사람의 정보는 실제다.

## 선택지
- 편집에서 흐리기: 원본 프레임에 실명이 남고, 스크롤하면 위치가 낡음
- 페이지에 CSS 흐림을 넣고 그 뒤에 찍기: 원본에도 안 남고 스크롤을 따라감

## 결정
페이지에 `<style>`(선택자 규칙)과 글자·모양 규칙(가장 안쪽 요소에 class, MutationObserver로 다시 그려도 유지)을 넣고, 넣었는지 확인한 뒤에만 캡처한다. 이동·새 탭·주소가 바뀌는 클릭·다시 읽기 동안은 캡처를 멈춘다. 필수 규칙이 10초 안에 0개면, 가리기 변수가 비어 있으면 녹화를 멈춘다. 실명은 `--var`로만 받아 실행 뒤 지우는 임시 파일로 넘기고, `run.mjs`·`timeline.json`에는 `***`로 쓴다. 이메일은 모양(`pattern`)으로 가리되 가상 도메인은 뺀다.

## 버린 것과 미룬 것
- `Page.addScriptToEvaluateOnNewDocument`로 새 문서 첫 순간부터 가리기: ego 지원 여부를 확인하지 않음. 지금은 캡처 멈춤으로 대신함

## 다시 볼 신호
- `transitions` 시트(전환 직후 3장씩)에서 한 장이라도 실명이 보이면 이 결정의 빈틈이다
