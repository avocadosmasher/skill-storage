# 006. 문장 교정 뒤 문단 연결과 생략된 관계 대상을 확인

- 날짜: 2026-11-03
- 상태: 채택
- 반영: skill-storage 1.12.0

## 배경

전체 원고의 외부 첨삭에서 문단 위치 이탈, 표·본문·결론의 중복, 긴 병렬 표현이 지적됐다. 후속 검토에서는 문법적으로 성립하는 표현을 비문으로 단정한 평가를 철회하고, 안내 표의 가시성과 사실의 확실성을 보존하도록 수정안을 조정했다. 이후 사용자는 정의 다음에 추상적인 준비 목적이 붙어 흐름이 끊기는 문제와, 포함되는 대상이 생략된 설명을 구체적으로 지적했다.

## 기존 기준과 남은 빈틈

- voice.md에는 추상 표현을 줄이고 대상·행동·결과를 밝히라는 기준이 이미 있다. 같은 금지 문장을 반복하지 않고 관계 대상이 불명확한 경우를 구체화한다.
- composition.md에는 설명의 연결과 요약 자료의 중복 축소 기준이 있다. 문장 교정 뒤 문단을 다시 읽는 절차와 표·본문·결론의 역할 대조를 보완한다.
- 사실·경험·계획의 구분과 확인되지 않은 내용을 만들지 않는 기준은 유지한다. 외부 평가를 정답으로 간주하거나 추가적인 검토 도구를 필수로 만들지 않는다.

## 결정

- 문장 표현을 고친 뒤 앞뒤 문단을 읽고, 앞 문장에서 다음 문장으로 설명이 이어지는지 점검한다. 중복되는 추상적 목적은 통합하거나 덜어내고, 필요한 관계가 빠졌으면 설명한다.
- 포함·전달·반영·연결의 대상이 문맥으로 명확하면 생략을 허용한다. 모호할 때 대상을 명시하며 도·까지 같은 강조 조사로 대상 명시를 대신하지 않는다.
- 여러 자료가 같은 내용을 반복하면 각각의 역할과 고유한 정보를 대조해 조정한다. 구조를 먼저 보려는 목적에 필요한 안내 표를 무조건 없애지 않는다.
- 문장 교정에서 선호와 문법 오류를 구분하고, 사실의 강도·주체·시점·인과를 보존한다. 기존 의미를 넘는 교정은 채택하지 않는다.
- 활성 기준은 voice.md·composition.md에 두고 SKILL의 전달 전 검토에서 연결한다. 사용자용 설명과 미배포 변경 기록을 맞춘다.

### 후속 구체화: 반복 표현을 실제 교정으로 연결

사용자는 과잉 규칙을 피하는 데 동의하면서도, 특정 표현을 금지하지 않는다는 설명만으로는 자주 반복하는 표현을 줄이지 못한다고 지적했다. 전면 금지 여부와 실제 교정 우선순위를 구분할 필요가 있어 다음을 voice.md에 편입했다.

- `것`으로 행위·방법·대상을 뭉뚱그린 표현은 더 구체적이고 자연스러운 대안이 있으면 우선 교정한다. 인접 문장에서 같은 명사형 표현이 반복되면 문단 전체를 다시 다듬는다.
- 기계적인 치환이 문장을 늘이거나 뜻을 흐리면 기존 표현을 유지한다. 고정된 사용 횟수나 일괄 금지는 두지 않는다.
- 포함·전달·반영 대상이 모호할 때는 명사 반복을 피하는 것보다 의미의 명확성을 우선한다. 대상이 분명한 경우의 생략은 허용한다.
- 이번 결과물의 목차·표 개수를 고정 템플릿으로 삼지 않는다는 기존 결정은 유지한다. 재사용할 것은 판단 기준이며, 결과물의 구체적인 모양은 글의 목적에 맞게 정한다.

## 채택하지 않은 규칙

- 것 표현의 일괄 금지, 명사·관계 대상의 매 문장 반복, 도·까지도 의무 사용. 이는 위의 조건부 교정 우선순위와 구분한다.
- 모든 문단을 정의·구성·목적의 순서로 고정하거나 접속어만 추가하는 교정.
- 특정 원고의 절·표 개수나 문단 이동을 다른 글의 공통 구조로 강제.
- 교정 모델의 단정과 구체화를 사실 확인 없이 지시문에 편입.

## 확인 범위와 다시 볼 신호

- 스킬 형식·문서 링크와 기존 변경 보존을 확인한다. 의미상 사례 대조는 로컬 검토이며 새 세션에서의 행동 재현이나 모델 학습 효과를 입증한 것으로 보고하지 않는다.
- 다음 글에서도 문장은 자연스럽지만 문단 연결이 끊기거나, 생략을 모두 없애 반복이 심해지거나, 요약 자료를 줄이며 가시성과 내용이 함께 사라지면 기준을 다시 조정한다.
