# thinking-aloud-writing 설계 기록

## 의도

공부 자료나 직접 만든 프로젝트를 기술 블로그 글로 옮기는 일을 돕는다. 에이전트는 대필자가 아니라 자료를 검토하고 구성을 잡는 편집자이자 공동 집필자다. 처음에는 저장소 주인의 블로그 글쓰기용으로 만들었고, 같은 문체가 마음에 드는 다른 사람도 쓸 수 있게 공개한다([001](./001-shareable-style-profile.md)).

## 현재 원칙

1. 문체 프로필(`references/voice.md`)은 특정 사람의 이름이 아니라 문체의 특징으로 설명한다. 사용자의 이번 지시와 직접 교정한 문장이 프로필보다 우선한다([001](./001-shareable-style-profile.md)).
2. 프로필이 어디서 왔는지는 근거 표의 블로그 글 링크로 남긴다([001](./001-shareable-style-profile.md)).
3. 사용자가 제공하지 않은 경험·감정·수치·출처는 만들지 않는다.
4. 소제목은 내용을 찾는 표지이며, 질문 중심 본문 전개와 형식을 구분한다. 글의 목적·정보의 변동성으로 설명 범위를 정하고, 사용자 수정본은 원문 비교로 반영한다([002](./002-findable-headings-and-editorial-scope.md)).
5. 현재 세션의 사용자를 저자로 간주한다. 지속 개선을 맡으면 수정 요청의 이유와 적용 범위를 분석하고 재사용할 기준을 스킬의 문체·구성·작업 지시문에 편입한다. 원고별 사실·예외와 추정은 확정 규칙으로 만들지 않는다([004](./004-incorporate-feedback-into-skill.md)).
